Підготовлено 2026-10-05. Власник відхилив звернення; збережено лише як чернетку. **Не надіслано**; власник може переглянути й передати
цей текст через офіційний контакт джерела. Credentials нашого OPDS не додаються.

Добрий день!

Я готую приватний OPDS-каталог Searchfloor для одного користувача FBReader.
Потрібно з'ясувати, чи дозволений такий автоматизований доступ і який спосіб
ви рекомендуєте: документований API, погоджений HTTP-клієнт або allowlist.
Обходити ваші challenge чи інші обмеження не планую.

Один діагностичний GET із нашого чинного Hetzner-хоста:

```text
Час: 2026-10-05 09:08:00.785 UTC
URL: https://searchfloor.org/?page=1&status=is_finished
User-Agent: opds-proxy/0.1
Accept: text/html,application/zip
HTTP: 403
Server: cloudflare
CF-Ray: a45b47809a219ea9-CDG
CF-Mitigated: challenge
Content-Type: text/html; charset=UTF-8
Retry-After: відсутній
```

Запит був без cookies, retries, переходу за redirects або proxy; challenge не
розв'язували. Перевіряли лише до 16 KiB відповіді в пам'яті, без збереження HTML.
Маркер challenge-title є; маркерів кодів 1010/1015 немає. Конкретне правило,
яке спрацювало, нам невідоме. Чи можете перевірити подію за CF-Ray і часом?

Планований клієнт запитує тільки потрібні сторінки списку/пошуку, без масового
сканування. HTML concurrency — 1, щонайменше 1 секунда між стартами запитів;
результати списку/пошуку кешуються на 15 хвилин. Файли передаються лише після
ручного Download користувачем, одна передача одночасно, без архівування книг.
На 403 клієнт припиняє запит; 429/5xx мають обмежену політику повтору й cooldown.
Можемо узгодити суворіші ліміти відповідно до ваших умов.

Підкажіть, будь ласка, чи дозволений цей сценарій і як отримати доступ без
challenge bypass. Якщо потрібне погодження адреси виходу для allowlist,
повідомте безпечний спосіб її передавання. Наш Cloudflare Tunnel обслуговує
власний приватний OPDS hostname й не керує захистом searchfloor.org.

До вашої відповіді прототип зупинений; отримання книг і подальші автоматизовані
перевірки джерела не виконуються.
